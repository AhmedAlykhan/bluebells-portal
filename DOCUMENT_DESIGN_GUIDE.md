# Bluebells Schooling System – Official Document Design Guide

**Target Institution:** Bluebells Schooling System, Latifabad, Hyderabad, Sindh, Pakistan  
**Audience:** Software Engineers, System Administrators, School Accounts Officers, and Print Operators  
**Scope:** Design standards, dimensional specifications, CSS print media rules, and typography for official school documents (Bank Fee Challans and Academic Examination Transcripts).

---

## 1. Introduction & Institutional Mandate

Official printed documents generated by school management software serve as legal proof of enrollment, provincial examination eligibility, and banking transactions. In Pakistan, private schooling standards regulated by the **Sindh Education & Literacy Department** and the **Board of Intermediate & Secondary Education (BISE) Hyderabad** impose strict layout, branding, and verification requirements.

This guide provides the definitive layout blueprints, color definitions, print stylesheets, and data field requirements for:
1. **Three-Copy Bank Fee Deposit Challan** (Bank Alfalah & Meezan Bank)
2. **Official Academic Transcript & Progress Report Card** (BISE Hyderabad Standard)

- **Paper Sizing:** Standard **A4 Landscape** (`297mm` width × `210mm` height / `11.69in` × `8.27in`).
- **Margins:** Top/Bottom `4mm`, Left/Right `4mm`.

- **Separators:** Vertical dashed border lines (`border-r border-dashed border-slate-500`) with designated scissor-cut markers (`✂ - - - - -`).

## 4. CSS `@media print` Implementation Rules

To ensure 100% pixel-perfect print output across Google Chrome, Safari, and Microsoft Edge:

### 4.1 Page Size Declaration
```css
@media print {
  /* Three-Copy Challan */
  @page {
    size: A4 landscape;
    margin: 4mm;
  }

  /* Academic Transcript (A3 Standard) */
  @page {
    size: A3 portrait;
    margin: 10mm;
  }
}
```

### 4.2 Exact Color Fidelity
Web browsers default to omitting background colors and gradients during printing. The print stylesheet must force color rendering:
```css
@media print {
  * {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }
}
```

### 4.3 Element Isolation & Chrome Suppression
During printing, all peripheral web chrome (headers, navigation drawers, buttons, footers, notifications) must be completely stripped from the render tree:
```css
@media print {
  /* Suppress UI controls */
  header,
  aside,
  footer,
  button,
  .print\:hidden {
    display: none !important;
  }

  /* Suppress browser URL headers/footers */
  body {
    background: white !important;
    color: black !important;
    margin: 0 !important;
    padding: 0 !important;
  }

  /* Prevent unintended page breaks within document cards */
  .challan-copy,
  .transcript-wrapper {
    break-inside: avoid !important;
    page-break-inside: avoid !important;
  }
}
```

### 4.4 Modal Print Activation Technique
When an interactive modal (like `FeeChallanModal` or `ReportCardModal`) triggers `window.print()`, the document body must be placed into print-modal mode:
```ts
// On Modal Open
document.body.classList.add('has-active-print-modal');

// On Modal Close
document.body.classList.remove('has-active-print-modal');
```
With corresponding CSS:
```css
body.has-active-print-modal {
  overflow: hidden;
}

@media print {
  body.has-active-print-modal > #root > *:not(#print-root) {
    display: none !important;
  }
}
```
